# Operations Analyzer — анализ банковских операций

Консольное приложение для анализа выгрузки операций: главная страница, события, отчёты и сервисные функции. Проект написан на Python 3.14, данные хранятся в Excel-файле, ответы выдаются в формате JSON.

## Возможности

Меню после запуска:

1. **Главная (JSON-ответ)** — приветствие по времени суток, карты с суммами трат за месяц, топ-5 транзакций, курсы валют и цены акций.
2. **События (JSON-ответ)** — события за период: неделя, месяц, год или всё время.
3. **Выгодные категории кешбэка** — повышенный кешбэк по категориям за выбранный месяц.
4. **Инвесткопилка** — расчёт «скруглений» транзакций и суммы, которую можно отложить за месяц.
5. **Простой поиск** — поиск операций по строке в описании.
6. **Поиск по телефонным номерам** — операции с номерами телефонов в описании.
7. **Переводы физическим лицам** — переводы частным лицам за период.
8. **Траты по категории** — сумма трат по категории с возможной датой отсчёта (обратные три месяца от неё).
9. **Траты по дням недели** — средние траты по каждому дню недели за последние три месяца.
10. **Траты в рабочий/выходной день** — средние траты в рабочие и выходные дни.

## Установка

```bash
git clone <адрес репозитория>
cd operations_analyzer
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
# .venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## Запуск

```bash
python src/main.py
```

Данные читаются из `data/operations.xlsx`. Для пунктов с датой используйте формат `2021-05-21` или `21.05.2021`; пустой ввод там, где дата необязательна, означает текущую дату.

## Структура проекта

```
operations_analyzer/
├── data/               # Excel-файл с операциями
├── logs/               # логи работы модулей
├── src/
│   ├── main.py         # меню и ввод пользователя
│   ├── utils.py        # вспомогательные функции (в т. ч. приветствие)
│   ├── views.py        # главная страница и события
│   ├── services.py     # кешбэк, инвесткопилка, поиск, переводы
│   └── reports.py      # отчёты по тратам
└── tests/              # pytest-тесты всех модулей
```

## Тесты и качество кода

```bash
pytest tests/ -v        # тесты
mypy .                  # проверка типов
flake8 src tests        # стиль кода
```

## Логирование

Модули пишут логи в `logs/`: имя модуля, функция, время события и сообщение. При ошибках в лог попадает трейсбэк.
